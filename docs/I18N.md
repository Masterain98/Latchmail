# Latchmail WebUI languages

Latchmail ships with Simplified Chinese (`zh-CN`) and English (`en`). On a first visit the WebUI checks the browser language list; any Chinese preference selects Chinese, otherwise it selects English. The language button is available on the sign-in card and in authenticated navigation. An explicit choice is stored as `latchmail.locale` in `localStorage` and applied on later visits.

Only the language preference is stored in browser storage. Authentication remains in the secure HttpOnly session cookie. Changing language updates visible copy, prompts, accessible labels, dates, document language, delivery states, and known API errors without changing the current route or reloading the application.

UI source copy uses Simplified Chinese as translation keys in `src/web/i18n.tsx`; protocol state keys have explicit labels in both languages. Add new user-facing copy to both dictionaries and cover language-sensitive behavior in unit or Playwright tests.
