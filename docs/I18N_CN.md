# Latchmail WebUI 多语言

Latchmail 提供简体中文（`zh-CN`）和英文（`en`）。首次访问时，WebUI 检查浏览器语言列表；只要存在中文偏好就选择中文，否则选择英文。登录卡片和已认证导航中都提供语言切换按钮。用户明确选择的语言保存在 `localStorage` 的 `latchmail.locale` 中，后续访问会继续使用该选择。

浏览器存储只保存语言偏好。认证仍然使用安全的 HttpOnly 会话 Cookie。切换语言会更新可见文本、提示、无障碍标签、日期、文档语言、投递状态和已知 API 错误，不会改变当前路由，也不会重新加载应用。

界面源文案以 `src/web/i18n.tsx` 中的简体中文作为翻译键；协议状态在两种语言中都有明确标签。新增用户可见文案时必须同时加入两个字典，并在单元测试或 Playwright 测试中覆盖语言相关行为。
